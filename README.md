
Blinkit Sales Data Analysis and Visualization

This project focuses on analyzing grocery sales data using Microsoft Excel to explore product-wise performance and generate meaningful business insights.

Project Objectives

- Analyze grocery sales data.
- Clean and organize raw data.
- Create Pivot Tables to summarize sales performance.
- Build charts and an interactive Excel dashboard.
- Present key business insights through data visualization.

Tools Used

- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Excel Dashboard

Project Files

- Raw Data: Original grocery sales dataset in CSV format.
- Excel Analysis: Workbook containing cleaned data, Pivot Tables, and dashboard.
- Dashboard Preview: Screenshot of the Excel dashboard.

Project Outcome

This project demonstrates practical Excel skills in data cleaning, sales analysis, summarizing data with Pivot Tables, and presenting insights through visualizations.
